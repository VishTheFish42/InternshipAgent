# SMS Consent & Opt-In Policy

InternshipAgent sends SMS alerts about new internship postings to the phone
number configured by the user (via the `ALERT_PHONE_NUMBER` environment
variable).

By running this software and providing a phone number in its configuration,
you consent to receive automated text messages from InternshipAgent,
including:

- Real-time alerts when a new internship posting matches your profile
- Batched summary alerts when multiple matches are found in a single cycle
- A weekly digest summarizing recent activity

**Message frequency** varies based on job posting activity and your
configured match threshold — typically a few messages per week, though this
can be higher during peak hiring seasons.

**Message and data rates may apply**, depending on your mobile carrier plan.

**Opt-out:** Reply **STOP** to unsubscribe from further messages at any time.

**Help:** Reply **HELP** for assistance, or see the project's
[README](README.md) for configuration details.

This is a personal, single-recipient tool — the phone number configured to
receive alerts belongs to the person running the software.
