`src/scrapers/llm_scrape.py`: fetches a resolved company's careers-page HTML and converts it to Markdown-style linked text via a small `html.parser.HTMLParser` subclass (`_LinkedTextExtractor`) — deliberately not a new BeautifulSoup/lxml dependency, same "plain stdlib over a library for a simple integration" call this project already made twice (Telegram in `notifier.py`, Supabase in `src/web/supabase_auth.py`). **Update 2026-11-02 (production outage found; backlog handling fixed; dead-man's switch added)**: Railway logs showed the worker down while still reporting `SUCCESS`: the Anthropic API was returning `credit balance is too low` (546 postings skipped across 55 batches in the 15:58 UTC run), and every Telegram `getUpdates` poll was returning `401 Unauthorized`. Investigating what would happen on recovery found a worse bug: in burst mode, `format_burst_message()` listed only the top `_BURST_MAX_LINES` (10) postings while `_notify_and_mark()` marked all of them notified, so most of a backlog would have been marked sent without ever being seen — contrary to the "send every posting" decision. Fixed: `format_burst_messages()` now returns one `BurstPart` per message and a posting is marked notified only if the message listing it was delivered; `_send_burst_parts()` lets only the first failure wait out the retry delay, so a dead token can't block a cycle for hours. `run_cycle()` now rechecks freshness before scoring and before alerting (`_still_fresh()`, falling back to `found_at` when a source gives no `posted_at`), so an outage's stale backlog doesn't spend credits or alert on dead listings. Added an optional `HEALTHCHECK_URL` dead-man's switch, pinged after a cycle only if not every source, scoring batch, or alert failed and Telegram's `getMe` doesn't reject the token; the ping URL is redacted from logs.

**Deploy order matters**: push this before restoring the Telegram token or adding Anthropic credits. Under the old code, a working token can release a burst that marks unseen postings as notified, and credits would be spent scoring the stale backlog.
